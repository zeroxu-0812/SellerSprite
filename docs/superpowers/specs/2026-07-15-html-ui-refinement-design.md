# products.html 观感优化设计

- 日期：2026-07-15
- 状态：已批准，待实现
- 涉及文件：`products.html`（模板，CSS + 内联 JS）

## 背景

`products.html` 是 sellersprite 爬虫的自包含富表格视图（双击 `file://` 打开，无需服务器）。当前是 16 列宽表（`min-width:1700px`，必然横向滚动），亚马逊深蓝 `#232f3e` + 橙 `#ff9900` 配色，正文 13px、大量 10–12px 小字，信息密集，整体偏"后台工具感"，对比强烈、留白少。

数据由 `html_render.py` 通过占位标记 `/*__DATA__*/.../*__END__*/` 注入到 `const DATA` 一行；模板里为 `{}` 时前端走 dropzone / 同目录 `fetch('products.json')` 兜底。

## 目标

在不改变数据字段和注入机制的前提下：
1. 提升视觉舒适度（保留亚马逊品牌识别）。
2. 加入让 16 列宽表更好用的轻量交互。

## 非目标（YAGNI）

- 不改 `html_render.py` 的注入机制。
- 不引入任何前端库（维持 `file://` 单文件自包含）。
- 不做列显隐 / 多条件区间筛选 / 明暗主题切换（本次范围外，留待后续）。
- 不改数据抓取逻辑或字段结构。

## 设计

### 1. 视觉精修（仅 CSS）

| 元素 | 现状 | 调整 |
|---|---|---|
| 页面背景 | `#f4f6f8` | `#f5f7fa`（更柔和） |
| 表头 | 深蓝 `#232f3e`（sticky） | 保留品牌色，加柔和下投影做分隔 |
| 强调橙 `#ff9900` | 大面积使用 | 收敛到趋势图 / 折扣% 等关键处 |
| 正文字号 | 13px、大量 10–12px 小字 | 正文 **13→14px**；层级靠字重而非缩小字号 |
| 单元格 padding | 10/12 | **12/14**，行高 1.5→1.7（更透气） |
| 分隔线 / 斑马纹 | `#eef0f2` + 隔行变色 | 更淡 `#f0f1f3`，**去掉斑马纹**，靠间距分区 |
| 表格容器 | 圆角 8、1px 边框 | 圆角 **12** + 柔和阴影 `0 1px 3px rgba(0,0,0,.06)` |
| 市场总览条 | 刺眼淡橙 `#fff7e6` / `#ffe2b3` | 柔和米色 `#fef9f0` / `#f5e6c8` |
| 行 hover | `#fafbfc` | 淡蓝 `#f0f7ff`（清晰但不刺眼） |

### 2. 实用交互（原生 JS）

- **表头点击排序**：数值列（价格 / 月销 / 评分 / 评论 / 销售额 / BSR 主排名）按数值排序；文本列（标题 / 品牌）按 `localeCompare`。点击切换 升↑ / 降↓，再点取消排序。表头显示当前排序的 `↑/↓` 指示。
- **顶部搜索框**：toolbar 新增 `<input>`，`oninput` 实时过滤（匹配 `title` / `asin` / `parent` / `brand` / `seller_name`，大小写不敏感）。`countText` 显示「命中 X / 共 Y」。
- **固定首列 + 表头**：主图列（`th`/`td`）`position:sticky; left:0` 并配不透明背景，横向滚动时主图不消失；表头 `sticky` 已有，保留。

### 3. 技术实现

- 全部改动落在 `products.html` 单文件（`<style>` 块 + `<script>` 块）。
- 排序 / 搜索均操作 `DATA.products`（过滤 + 排序后的副本），交由现有 `render()` 重渲染 `<tbody>`，不动每行的 `renderRow` 富单元格逻辑。
- 排序状态用模块内变量 `sortKey` / `sortDir` 持有；搜索关键字 `query` 持有；二者任一变化即重新计算可见行集合并渲染。
- `/*__DATA__*/{}/*__END__*/` 注入标记保持不变，`html_render.py` 不动。

## 范围与回归

- 改动仅限 `products.html`。
- `tests/test_pipeline.py` 中对 HTML 的断言（`'"asin": "B0F1QHNFJP"'`、`'"sample_size": 2'`）仍成立——它们校验的是注入的数据，与 CSS/交互无关。
- 实现完成后，用当前 `output/` 下 14 条商品数据重新渲染 `output/products.html`（调用 `html_render.render_html`，无需重新抓取）。

## 实现要点 / 边界

- 排序需区分数值与文本：给每个可排序列声明一个类型标记（数值 / 文本 / 排名），避免字符串字典序错误。
- 空值（`null`/`undefined`/`''`）在排序时统一沉底，不破坏顺序。
- 固定首列的 sticky 背景必须不透明，否则滚动时下方内容透出。
- 搜索为子串包含匹配，非模糊/分词；保持轻量。
